# Hamza Mushtaq — Portfolio

Personal portfolio website of Hamza Mushtaq, Senior WordPress & Shopify Developer.

Live: https://hamzamushtaq-dev.github.io/

Plain HTML, CSS and JavaScript, hosted on GitHub Pages.

## Adding a project
1. Add a 1200×750 screenshot to `assets/projects/<slug>.jpg`
2. Copy an existing `<a class="project reveal">` card inside `#projects` in `index.html`, update the link, image, type, title, description and platform, and renumber the cards
3. Update the "Live projects featured below" count in the About stats

## Updating the CV
Replace `assets/Hamza-Mushtaq-CV.pdf` with the new PDF (keep the same file name).
